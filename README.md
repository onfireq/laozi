# 观道 · 道德经研习

用于学习、深入了解并洞察《道德经》的纯静态网页。以王弼通行本为底本，参楼宇烈校注，融今译与义理阐发。

## 功能

- **八十一章全文**：道经 37 章 + 德经 44 章，每章含原文、今译、研读解析、核心名句；支持搜索与道经/德经筛选
- **核心概念**：10 个贯穿全书的概念（道、德、无为、自然、柔弱、反、无、朴、水、虚静），每个含定义、相关章节、深入洞察
- **名句速查**：37 条传世名句，一键跳转所在章节
- **入门研习**：5 篇导学文章（历史与版本、思想地图、无为与自然、修身处世、现代启示）
- 深色 / 宣纸双主题，记忆偏好；hash 路由，可离线双击使用

## 文件

| 文件 | 说明 |
|------|------|
| index.html | 页面骨架（hash 路由单页应用） |
| style.css | 样式（墨色 × 朱砂 × 金 × 宣纸，双主题） |
| data.js | 八十一章全文 + 概念 + 名句 + 文章数据 |
| app.js | 路由、渲染、搜索、主题切换等逻辑 |

## 本地预览

直接双击 `index.html` 即可（纯静态、零依赖）。

## 部署到 GitHub Pages

1. 新建仓库（如 `laozi`）
2. 将本目录文件推送到仓库 main 分支
3. 仓库 Settings → Pages → Source 选择 `main` 分支 / root 目录
4. 访问 `https://<用户名>.github.io/<仓库名>/`

或与既有站点集成：把本目录文件放入 Next.js 项目的 `public/laozi/`，构建后即可在 `/laozi/` 访问。
